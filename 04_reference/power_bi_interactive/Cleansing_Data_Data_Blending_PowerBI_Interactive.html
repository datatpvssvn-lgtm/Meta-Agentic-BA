2. Ba kỹ thuật Data Blending

Cách phân biệt dễ nhớ: Append/Union cộng THEO DÒNG, Merge cộng THEO CỘT, còn Combine from Folder là Append tự động hoá cho cả folder.

APPEND Union Query

  • Gộp theo DÒNG — xếp chồng bảng
  • Điều kiện: các bảng phải cùng cấu trúc cột
  • Kết quả: số dòng tăng, số cột giữ nguyên
  • Tương đương SQL: UNION ALL

MERGE Join Query

  • Gộp theo CỘT — nối thêm cột
  • Điều kiện: cần 1 cột khoá chung (Key)
  • Kết quả: số cột tăng, số dòng tuỳ kiểu Join
  • Tương đương SQL: JOIN

FOLDER Combine Files

  • Gộp theo DÒNG, tự động cho cả folder
  • Điều kiện: file cùng định dạng & cấu trúc
  • Kết quả: tự thêm cột Source.Name
  • Tương đương SQL: UNION ALL qua vòng lặp

4. Merge (Power Query) khác VLOOKUP (Excel) như thế nào?

Khác biệt rõ nhất lộ ra khi khoá CustomerID C01 bị lặp lại ở CẢ HAI bảng: Sales có 2 đơn hàng của C01 (bình thường — khách mua nhiều lần), còn Customer lại có 2 bản ghi cho C01 (bất thường — lỗi nhập liệu 2 lần). Khi 1 khoá lặp ở cả 2 bên, Merge sẽ nhân chéo — đây là lúc thấy rõ nhất VLOOKUP và Merge lệch nhau.

5. Fuzzy Matching — minh hoạ bằng biểu đồ độ giống nhau

Dùng khi cột khoá của 2 bảng ghi tên hơi khác nhau (viết tắt, dấu câu, khoảng trắng...). Kéo thanh trượt Similarity Threshold để xem cặp nào đủ điểm để Power Query tự ghép — điểm số được tính trực tiếp bằng thuật toán Levenshtein, giống cách Power Query thực hiện.

6. Spatial Matching — minh hoạ bằng bản đồ khu vực bán hàng

Dùng khi 2 bảng không có cột chung để Merge, phải ghép theo vị trí. Ví dụ: gán khách hàng vào cửa hàng nằm trong bán kính phục vụ (trade area) gần nhất. Bấm "Chạy Spatial Match" để xem animation ghép nối.

7. Ứng dụng Power BI & AI

Fuzzy Merge có sẵn trong Power Query

Trong hộp thoại Merge, tick "Use fuzzy matching to perform the merge", kéo thanh Similarity threshold (0–1), có thể thêm Transformation Table để tự map từ đồng nghĩa (vd "Cty" = "Công ty").

Copilot trong Power BI / Fabric

Copilot gợi ý mô tả dữ liệu, tự viết DAX measure, tóm tắt report bằng ngôn ngữ tự nhiên; trong Dataflow Gen2, Copilot còn gợi ý bước Power Query tiếp theo khi làm sạch dữ liệu.

AI / Semantic Matching nâng cao

Khi Levenshtein/Jaro không đủ (khác ngôn ngữ, viết tắt phức tạp), có thể gọi Azure AI (Cognitive Services) hoặc model embedding qua "Invoke Custom Function" / Python script để so khớp theo ngữ nghĩa thay vì ký tự.

Shape Map & Azure Maps cho Spatial

Power BI có visual Shape Map (theo địa giới hành chính) và Azure Maps (theo toạ độ), hoặc dùng Python/R visual (geopy, shapely) để tính point-in-polygon trước khi Load vào Data Model.
