Hướng dẫn Power Query — Đầy đủ theo Ribbon Menu

Tổng hợp tất cả kỹ thuật biến đổi dữ liệu được tổ chức theo đúng các tab trên thanh ribbon của Power Query Editor. Dễ tra cứu, dễ áp dụng.

Home – Làm sạch cơ bản
Transform – Biến đổi dữ liệu

1. Xóa trùng lặp — Remove Duplicates

Reduce Rows
Home Reduce Rows → Remove Rows → Remove Duplicates

Giữ hàng đầu tiên, xóa các hàng trùng phía sau dựa trên cột bạn chọn.

❌ Trước

KH002Tran B
KH002Tran B
→
✅ Sau
MaKHTenKH
KH001Nguyen A
KH002Tran B
M= Table.Distinct(Source, {"MaKH"})
⚠️

2. Xóa / Thay thế lỗi — Remove / Replace Errors

Reduce Rows
Home Reduce Rows → Remove Rows → Remove Errors  |  hoặc Right-click → Replace Errors

Lỗi xuất hiện khi ô dữ liệu không thể đọc đúng (chia cho 0, kiểu sai...). Có 2 lựa chọn: xóa hàng lỗi hoặc thay bằng giá trị mặc định.

🗑️ Remove Errors

Xóa toàn bộ hàng chứa lỗi

Table.RemoveRowsWithErrors(Source, {"DoanhThu"})

🔄 Replace Errors

Thay lỗi bằng giá trị khác (ví dụ 0)

Table.ReplaceErrorValues(Source, {{"DoanhThu", 0}})
🔽

5. Xóa khoảng trắng — Trim & Clean

Text Column
Transform Text Column → Format → Trim / Clean

Trim = xóa khoảng trắng đầu/cuối. Clean = xóa ký tự ẩn không in được. Nên dùng cả hai cùng lúc.

M= Table.TransformColumns(Source, {{"TenKH", each Text.Trim(Text.Clean(_)), type text}})
🔄

6. Thay thế giá trị — Replace Values

Transform
Home Transform → Replace Values  |  hoặc Right-click cột → Replace Values

Đổi giá trị cũ thành giá trị mới trong cột. Ví dụ: chuẩn hóa tên vùng "HN" → "Ha Noi".

M= Table.ReplaceValue(Source, "HN", "Ha Noi", Replacer.ReplaceText, {"KhuVuc"})
🔍

7. Lọc hàng — Filter Rows

Reduce Rows
Home Reduce Rows → Keep Rows / Remove Rows  |  hoặc click ▼ đầu cột

Click ▼ ở đầu cột để lọc. Bỏ tick (null) để loại hàng trống, hoặc dùng Number/Text/Date Filters cho điều kiện phức tạp.

M= Table.SelectRows(Source, each [DoanhThu] > 0 and [KhuVuc] <> null)
✂️

9. Ghép cột — Merge Columns

Text Column
Transform Text Column → Merge Columns  |  hoặc Right-click chọn nhiều cột

Giữ Ctrl + click chọn nhiều cột → Right-click → Merge Columns. Chọn separator và đặt tên cột mới.

M= Table.CombineColumns(Source, {"Ho", "Ten"}, Combiner.CombineTextByDelimiter(" "), "HoTen")

Text Column

UPPERCASE

lowercase

Chữ đầu mỗi từ viết hoa

Tab Transform thay đổi dữ liệu trực tiếp trên cột/bảng hiện có — khác với Add Column là tạo cột mới. Tất cả thay đổi đều được ghi lại thành Applied Steps.
📊

T1. Nhóm dữ liệu — Group By

Table
Home hoặc Transform → Table → Group By

Tương tự hàm SUMIF / COUNTIF trong Excel — gộp nhiều hàng thành một dựa trên giá trị của cột nhóm, rồi tính tổng, đếm, trung bình...

1
Vào Home → Group By (hoặc tab Transform → Group By)
2
Group by column: chọn cột muốn nhóm (ví dụ: KhuVuc)
3
New column name: đặt tên cột kết quả, chọn Operation (Sum, Count, Average, Min, Max...)
❌ Trước
KhuVucTenKHDoanhThu
Mien BacNguyen A5,000,000
Mien BacTran B3,000,000
Mien NamLe C7,000,000
Mien NamPham D2,000,000
→
✅ Sau (Group By KhuVuc → Sum)
KhuVucTongDoanhThuSoKhachHang
Mien Bac8,000,0002
Mien Nam9,000,0002
M= Table.Group(Source, {"KhuVuc"}, {
  {"TongDoanhThu", each List.Sum([DoanhThu]), type number},
  {"SoKhachHang", each Table.RowCount(_), type number}
})
🔀

Pivot biến các giá trị trong một cột thành tiêu đề cột mới. Dùng khi bạn có dữ liệu dạng "dọc" muốn chuyển sang dạng "ngang" để dễ so sánh.

ThangNamSanPhamDoanhThu

T1/2024San Pham B5,000,000
T2/2024San Pham A12,000,000
T2/2024San Pham B8,000,000
→
✅ Dạng ngang (Pivoted)
ThangNamSan Pham ASan Pham B
T1/202410,000,0005,000,000
T2/202412,000,0008,000,000
1
Chọn cột chứa giá trị muốn thành tiêu đề (ví dụ: cột SanPham)
2

3

Nếu bạn muốn làm ngược lại (cột → hàng), dùng Unpivot Columns ở bên dưới (T3).

T3. Unpivot Columns — Chuyển cột thành hàng

Any Column
Transform Any Column → Unpivot Columns / Unpivot Other Columns

Ngược lại với Pivot — chuyển dữ liệu dạng "ngang" (nhiều cột tháng/quý) thành dạng "dọc". Đây là bước cần thiết để Power BI có thể tính toán theo thời gian.

❌ Dạng ngang
SanPhamT1T2T3
San Pham A10tr12tr9tr
San Pham B5tr8tr6tr
→
✅ Dạng dọc (chuẩn cho Power BI)
SanPhamThangDoanhThu
San Pham AT110tr
San Pham AT212tr
San Pham BT15tr
San Pham BT28tr
1
Chọn các cột không muốn unpivot (ví dụ: cột SanPham)
2

3
Đổi tên 2 cột mới: Attribute → "Thang", Value → "DoanhThu"
M= Table.UnpivotOtherColumns(Source, {"SanPham"}, "Thang", "DoanhThu")

T4. Đổi chỗ hàng và cột — Transpose

Table
Transform Table → Transpose

Chuyển hàng thành cột và cột thành hàng. Thường dùng khi dữ liệu từ nguồn bị thiết kế ngược (tiêu đề ở cột thay vì hàng).

⚠️
Sau khi Transpose, thường cần bấm thêm Use First Row as Headers để đặt hàng đầu tiên làm tiêu đề cột.
1
Tab Transform → nhóm Table → Transpose
2
Tab Transform → Use First Row as Headers (nếu cần)
M= Table.Transpose(Source)

T5. Trích xuất text — Extract

Text Column
Transform Text Column → Extract

Lấy một phần của chuỗi: N ký tự đầu/cuối, ký tự theo vị trí, phần text trước/sau một ký tự phân cách.

First Characters

Lấy N ký tự đầu

Text.Start([col], 3)

Last Characters

Lấy N ký tự cuối

Text.End([col], 4)

Range

Lấy từ vị trí X, lấy N ký tự

Text.Middle([col], 2, 5)

Text Before Delimiter

Lấy phần trước ký tự phân cách

Text.BeforeDelimiter([col], "@")

Text After Delimiter

Lấy phần sau ký tự phân cách

Text.AfterDelimiter([col], "@")

Text Between Delimiters

Lấy phần giữa 2 ký tự

Text.BetweenDelimiters([col],"(","")")
❌ Email gốc
Email
nguyen.a@gmail.com
tran.b@company.vn
→
✅ Lấy phần trước @
Username
nguyen.a

T8. Dòng đầu làm tiêu đề — Use First Row as Headers

Table
Home Transform → Use First Row as Headers

Khi dữ liệu nguồn không nhận ra hàng tiêu đề, Power Query gán tên Column1, Column2... Bấm nút này để dùng hàng đầu tiên làm tên cột.

1
Tab Home → nhóm Transform → Use First Row as Headers
2
Ngược lại, Use Headers as First Row để hạ tiêu đề xuống thành dữ liệu
M= Table.PromoteHeaders(Source, [PromoteAllScalars=true])
💡
Tab Add Column luôn tạo cột mới, không thay đổi cột gốc. Đây là sự khác biệt quan trọng so với tab Transform.

AC1. Tạo cột bằng công thức — Custom Column

General
Add Column General → Custom Column

Viết công thức M tùy ý để tạo cột mới. Đây là tính năng linh hoạt nhất trong Add Column — bạn có thể tính toán, nối chuỗi, xử lý điều kiện phức tạp.

1
Tab Add Column → Custom Column
2
Đặt tên cột mới, viết công thức trong ô Custom column formula
3
Tham chiếu đến cột khác bằng cú pháp: [TenCot]

Ví dụ 1: Tính doanh thu sau thuế

Custom column formula
= [DoanhThu] * 0.9

Ví dụ 2: Nối họ tên

Custom column formula
= [Ho] & " " & [Ten]

Ví dụ 3: Phân loại theo điều kiện

Custom column formula
= if [DoanhThu] >= 10000000 then "VIP" else "Thuong"

Ví dụ 4: Tính số ngày từ ngày đặt

Custom column formula
= Duration.Days(DateTime.LocalNow() - [NgayDat])
💡
Trong hộp thoại Custom Column, bên phải có danh sách Available columns — double-click để chèn tên cột vào công thức thay vì gõ tay.
🔀

AC2. Cột điều kiện — Conditional Column

General
Add Column General → Conditional Column

Tạo cột mới dựa trên điều kiện IF/THEN/ELSE — giống như hàm IFS trong Excel nhưng có giao diện trực quan, không cần gõ công thức.

1
Tab Add Column → Conditional Column
2
Đặt tên cột mới, thêm các điều kiện If... Then... Else...
3
Bấm Add Clause để thêm điều kiện (tương đương ELSE IF)

Ví dụ: Phân hạng khách hàng theo doanh thu

IF
DoanhThu >= 50,000,000
→ "Bạch Kim"
ELSE IF
DoanhThu >= 20,000,000
→ "Vàng"
ELSE IF
DoanhThu >= 5,000,000
→ "Bạc"
ELSE
(không thỏa điều kiện nào)
→ "Thường"

Bạn chỉ cần gõ ví dụ kết quả mong muốn, Power Query tự đoán công thức và áp dụng cho toàn bộ. Không cần biết cú pháp M Language!

1
Tab Add Column → Column from Examples → From All Columns
2
Một cột mới trống xuất hiện bên phải. Gõ ví dụ vào ô đầu tiên (ví dụ: "2024" từ cột ngày "15/03/2024")
3
Power Query tự đề xuất công thức và điền toàn bộ. Nếu đúng, bấm OK.
💡
Đây là tính năng mạnh nhất cho người mới — không cần nhớ hàm M. Thử gõ ví dụ như "Tháng 3/2024", "NGUYEN VAN A", "nguyen.a" (từ email) và xem Power Query đề xuất gì.
🔢

AC4. Đánh số thứ tự — Index Column

General
Add Column General → Index Column → From 0 / From 1 / Custom

Thêm cột số thứ tự tự động. Hữu ích khi bảng không có khóa chính (primary key) hoặc cần đánh số lại sau khi lọc.

From 0

Bắt đầu từ 0, 1, 2...

Table.AddIndexColumn(Source, "Index", 0, 1)

From 1

Bắt đầu từ 1, 2, 3...

Table.AddIndexColumn(Source, "Index", 1, 1)

Custom

Tự chọn điểm bắt đầu và bước nhảy

Table.AddIndexColumn(Source, "STT", 100, 10)

Power BI Desktop vs Power BI Service

Power BI có 2 môi trường chính. Hiểu rõ sự khác biệt để biết nên làm gì ở đâu.

💻 Power BI Desktop
✅ Kết nối nhiều nguồn dữ liệu
✅ Làm sạch & transform bằng Power Query
✅ Tạo Data Model, Relationship
